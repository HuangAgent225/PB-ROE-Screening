# Trae PB-ROE 价值选股 Skill

![License](https://img.shields.io/badge/License-MIT-blue.svg)
![Trae](https://img.shields.io/badge/Trae-Skill-0a84ff)

基于 PB-ROE 框架的 A 股价值选股工具：**五维 17 因子量化评分 + 14 行业专属权重**，输出结构化分析报告。

## 简介

PB-ROE 是 A 股最经典的价值投资框架之一。核心理念：

> ROE 越高的公司，市场理应给予越高的 PB。如果一只股票的 PB 相对于其 ROE 明显偏低，就意味着它被市场低估了。

本 Skill 将这一理念系统化为 **5 个维度 × 17 个因子** 的量化评分体系，覆盖估值、盈利质量、成长性、财务健康和安全边际，输出结构化的分析报告。

与"一套模板打天下"的做法不同，本 Skill 的核心升级在于**行业差异化权重**：用 2011-2025 年 A 股真实数据对 14 个申万一级行业逐一回测，通过信息系数（IC）加权推导出各行业专属的五维权重，并在使用时根据股票所属行业自动套用。

## 核心特性

1. **五维 17 因子评分体系**：每个因子有明确的分档打分规则，满分 100 分，输出星数评级。
2. **行业专属权重自动套用**：覆盖 14 个申万一级行业白名单，无需手动指定权重；未覆盖行业回退默认权重。
3. **基于回测的权重来源**：所有行业权重均来自 2011-2025 年、15 个调仓日的 IC 加权推导，并通过样本外（OOS）检验。
4. **价值陷阱识别**：两项一票否决（ROE 为负、资产负债率 > 85%）+ 周期行业"景气高点低 PB 陷阱"提示。
5. **结构化报告输出**：核心数据、逐因子打分明细、杜邦分析、同行业 PB-ROE 回归定位、综合结论。

## 框架（默认权重）

| 维度 | 默认权重 | 因子数 | 核心指标 |
|------|---------|--------|---------|
| 估值 | 30% | 3 | PB-ROE 偏离度、PB 行业分位、PB/ROE 性价比 |
| 盈利质量 | 25% | 4 | ROE 绝对值、ROE 5 年稳定性、ROE 趋势、杜邦质量 |
| 成长性 | 20% | 3 | 营收 CAGR、净利润 CAGR、ROE 增长动量 |
| 财务健康 | 15% | 4 | 资产负债率、利息覆盖倍数、现金流质量、商誉占比 |
| 安全边际 | 10% | 3 | PB 历史分位、股息率、破净程度 |

默认权重为兜底方案，仅用于未纳入行业白名单或未生成优化权重的标的。

## 行业优化权重

### 生成方法

- **数据范围**：2011-2025 年 A 股，每个行业取申万一级全部成分股；
- **调仓规则**：每年年报披露截止后（4 月 30 日）按行业打分，共 15 个调仓日；
- **权重推导**：计算各维度与未来 1 年 / 3 年收益的 Spearman Rank IC，用 mean IC 加权 + 同向比例过滤，再按 `0.7 × IC 权重 + 0.3 × 默认权重` 收缩，得到行业专属权重；
- **样本外验证**：训练期 2011-2018 推导权重，2019-2025 作为 OOS 检验，OOS IC 保持正向才发布。

### 申万一级白名单（14 个）

银行 / 非银金融 / 房地产 / 钢铁 / 有色金属 / 基础化工 / 建筑材料 / 交通运输 / 公用事业 / 家用电器 / 食品饮料 / 建筑装饰 / 煤炭 / 石油石化

> 白名单外行业（如计算机、医药生物、电子等轻资产/高成长行业）建议改用 PE-PEG 或 DCF 框架。

## 评级标准

| 得分 | 星数 | 含义 |
|------|------|------|
| 85-100 | ★★★★★ | PB-ROE 黄金坑，安全边际极高 |
| 70-84 | ★★★★☆ | 显著低估，重点关注 |
| 55-69 | ★★★☆☆ | 合理偏低，放入观察池 |
| 40-54 | ★★☆☆☆ | 估值合理，建议观望 |
| < 40 | ★☆☆☆☆ | PB 虚高或价值陷阱，回避 |

两项一票否决（任一触发直接降为 1 星）：

1. **ROE 为负** → 不适用 PB-ROE 框架；
2. **资产负债率 > 85%** → 财务风险过高（金融业豁免）。

## 安装

1. 下载本仓库的 `SKILL.md` 与 `industry_weights.json` 两个文件；
2. 放入 Trae 项目的 `.trae/skills/pb-roe-screening/` 目录：

```
你的Trae项目/.trae/skills/pb-roe-screening/
├── SKILL.md
└── industry_weights.json
```

3. 在 Trae 中对话时，提到"PB-ROE 选股""价值股筛选"即可自动触发。

```bash
# 直接 clone 使用
git clone https://github.com/HuangAgent225/PB-ROE-Screening.git
mkdir -p 你的Trae项目/.trae/skills/pb-roe-screening
cp PB-ROE-Screening/SKILL.md PB-ROE-Screening/industry_weights.json 你的Trae项目/.trae/skills/pb-roe-screening/
```

> `industry_weights.json` 必须与 `SKILL.md` 位于同一目录，否则行业优化权重无法生效，工具将回退默认权重。

## 输出内容

- 核心数据一览（PB / ROE / PB÷ROE / 市值）；
- 五维 17 因子逐项打分明细；
- 杜邦分析（ROE 驱动来源拆解：净利率 / 周转率 / 杠杆）；
- 同行业 PB-ROE 回归定位与偏离度；
- 综合评分 + 星数评级 + 投资结论。

## 注意事项

- **行业权重自动套用**：无需手动指定行业权重，工具会按 `industry_weights.json` 自动匹配；行业名支持模糊匹配（如"商业银行"→"银行"）。
- **组合化需谨慎**：白名单中仅家用电器、交通运输、钢铁等少数行业的 Top5 等权组合表现可用，其余行业权重建议仅用于个股排序参考。
- **周期行业低 PB 陷阱**：钢铁、化工、有色等行业在景气高点常呈现低 PB 特征（PB 历史分位 < 10% 且 ROE 大幅上升），需结合景气位置判断。
- **ROE 为负的公司不适用此框架**。
- **轻资产公司**（创业板/科创板）PB 参考意义有限，需结合 PE 辅助判断。
- **权重会随数据更新**：重新生成权重的方法见 `SKILL.md` 中"权重更新"一节。
